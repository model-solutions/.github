## Model Solutions Nedir?

**Model Solutions**, Model Bilgi İşlem tarafından geliştirilen kurumsal iş uygulamaları, sektörel çözümler, ERP bağlantılı modüller ve operasyonel yazılım projelerinin toplandığı organizasyondur.

Bu alan; insan kaynakları, varlık yönetimi, barkod operasyonları, planlama, tedarikçi yönetimi, mobil saha uygulamaları, web uygulamaları ve kuruma özel iş çözümleri için kullanılır.

Model Framework altyapıyı kurar.  
Model Docs bilgiyi düzenler.  
**Model Solutions ise gerçek iş problemlerini çözen uygulamaları barındırır.**

---

## Temel Amaç

Kurumsal firmalarda her departmanın, her operasyonun ve her sektörün farklı ihtiyaçları vardır.

**Model Solutions** bu ihtiyaçlara karşılık gelen uygulama ve çözüm projelerini düzenli, anlaşılır ve yönetilebilir bir yapı altında toplamak için oluşturulmuştur.

Hedefimiz:

- İş uygulamalarını tek bir çözüm ekosisteminde toplamak
- ERP ile bağlantılı modülleri düzenli hale getirmek
- Mobil, web ve masaüstü uygulamaları sınıflandırmak
- Dikey sektör çözümlerini ayrıştırmak
- Müşteri veya ürün bazlı uygulamaları daha yönetilebilir kılmak
- Eski, aktif ve deneysel projeleri birbirinden ayırmak
- Repository karmaşasını azaltmak
- Her uygulamanın amacını, durumunu ve teknik yapısını görünür hale getirmek

Kısacası:  
128 repo aynı sepete atılmasın; her çözüm kendi rafında dursun.

## Ekosistem Kapsamı

Model Solutions organizasyonu aşağıdaki çözüm alanlarını kapsar:

| Alan | Açıklama |
|---|---|
| Business Applications | Kurumsal iş süreçlerini yöneten uygulamalar |
| ERP Modules | ERP ile ilişkili modül ve yardımcı uygulamalar |
| Mobile Solutions | Mobil saha, takip ve operasyon uygulamaları |
| Web Applications | Web tabanlı iş uygulamaları |
| Desktop Applications | Masaüstü yönetim ve operasyon araçları |
| Vertical Solutions | Sektörel veya departman bazlı özel çözümler |
| Workflow Applications | İş akışı, onay, takip ve planlama sistemleri |
| Management Tools | Operasyon yönetimi ve kontrol uygulamaları |
| Internal Applications | Şirket içi kullanım odaklı uygulamalar |
| Customer-Specific Apps | Müşteri veya projeye özel geliştirilmiş çözümler |

## Repository İsimlendirme Standardı

Bu organizasyonda repo isimleri küçük harfli, tireli ve anlaşılır olmalıdır.

Önerilen prefix yapısı:

```txt
app-*        → genel iş uygulaması
web-*        → web uygulaması
mobile-*     → mobil uygulama
desktop-*    → masaüstü uygulama
module-*     → ERP / sistem modülü
service-*    → servis veya backend servis yapısı
client-*     → müşteriye özel uygulama
template-*   → uygulama şablonu
sample-*     → örnek uygulama
archive-*    → arşivlenmiş veya eski proje
